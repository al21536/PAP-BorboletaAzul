# PAP-BorboletaAzul
No âmbito da Prova de Aptidão Profissional do curso de Técnico de Informática - Sistemas, apresento o seguinte projeto: o desenvolvimento de um website institucional para a Fundação Borboleta Azul. Esta organização é criada com a missão de apoiar crianças e jovens que enfrentam a realidade do cancro, servindo como um suporte.
